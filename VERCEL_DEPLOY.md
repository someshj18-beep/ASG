# Deploy Arctic Staffing Global to Vercel

This site is a static Vite build. The repository includes a root `vercel.json`
with the install command, build command, and output directory configured.

1. Import this repository in Vercel.
2. Keep the project Root Directory set to the repository root.
3. Deploy with the detected Vite framework preset.

No backend service or environment variables are required for the site.
